# Python · A/B-тесты

## Структура папки

- `Python_AB_tests_1.ipynb` — разработка A/B‑теста и анализ результатов (EDA → дизайн эксперимента → мониторинг → статистическая проверка гипотез).
- `Python_AB_tests_2.ipynb` — A/B/C‑эксперимент для сервиса такси «Карету мне»: расчёт параметров теста, проверка корректности сплита и анализ метрик.
- `Python_AB_tests_3.ipynb` — исследование результатов A/B‑теста (онбординг) и поиск инсайтов: анализ исторических данных и результатов эксперимента, сравнение конверсий и депозитов.
- `Data_analysis_diploma.ipynb` — дипломный кейс продуктовой аналитики маркетплейса: метрики, юнит‑экономика, сегментация, рекомендации и A/B‑эксперимент по бонусу для одного из канаолов привлечения аудитории.

> Примечание: в этой папке нет файлов `*.py`. Вся логика реализована в ноутбуках. Если нужен экспорт в `.py`, можно конвертировать ноутбук через `jupyter nbconvert --to script <notebook.ipynb>`.

## Постановка задачи (`Python_AB_tests_2.ipynb`)

Вы выступаете в роли продуктового аналитика сервиса такси. Discovery показало рост отмен, когда прогноз времени ожидания не совпадает с фактическим. Команда сделала новую модель прогноза (2 варианта), и её нужно проверить через A/B/C‑эксперимент.

Цели работы:
- определить и рассчитать параметры теста;
- оценить корректность проведения теста;
- проанализировать результаты теста.

Данные: три таблицы `users`, `events`, `orders` (период 2024‑01‑01…2024‑10‑27, события/заказы 2024‑09‑23…2024‑10‑27) — описание полей приведено в файле задания.

## Постановка задачи (`Python_AB_tests_3.ipynb`)

Проверяется гипотеза о влиянии **нового онбординга** на поведение и активность пользователей финансового сервиса:
- исторические данные по новым пользователям за период **2025‑04‑01…2025‑06‑01** (события до второго депозита);
- данные A/B‑эксперимента по пользователям, зарегистрировавшимся **2025‑06‑02…2025‑06‑15**, пользователи уже размечены на группы `control/test`.

## Постановка задачи (`Data_analysis_diploma.ipynb`)

Кейс маркетплейса за 2024 год: нужно собрать обзор ключевых продуктовых метрик, оценить монетизацию и юнит‑экономику (CAC/LTV/ROI), найти инсайты через сегментацию и сформулировать рекомендации. Дополнительно — спроектировать и оценить эксперимент «бонус на первую покупку» для пользователей из канала TikTok.

## Что сделано в файлах

### `Python_AB_tests_1.ipynb`

Содержимое ноутбука организовано по этапам эксперимента:
- **EDA исторических данных**: загрузка датасета с сессиями, базовые проверки качества, агрегирование по пользователям/датам, исследование регистраций и просмотров.
- **Дизайн A/B‑теста**: формулировка H0/H1, расчёт размера выборки и длительности теста.
- **Мониторинг**: проверки распределения пользователей по группам, пересечений пользователей, равномерности по платформам/регионам.
- **Анализ результатов**: расчёт ключевой метрики и статистическая проверка (используются `scipy.stats`, `statsmodels`).

Технически:
- библиотеки: `pandas`, `matplotlib`, `scipy.stats`, `statsmodels.stats.*`;
- источники данных подгружаются по URL (в ноутбуке есть `pd.read_csv('https://code.s3.yandex.net/datasets/...')`).

### `Python_AB_tests_2.ipynb`

В ноутбуке реализованы ключевые шаги A/B/C‑анализа:
- **Параметры теста и MDE**: задаются `alpha` с поправкой на множественные сравнения (`0.05 / 3`), `beta`, число групп и доля трафика; рассчитывается MDE для метрики‑отношения через квантили распределения Стьюдента.
- **Проверка корректности сплита**: поиск пользователей, попавших более чем в одну группу, и дальнейшая работа с корректной таблицей сплита.
- **Подготовка данных**: загрузка `orders/events/split_data` и объединение с группами эксперимента.
- **Кумулятивные метрики**:
  - ключевая метрика (по заказам: расчёт кумулятивных значений по датам и группам);
  - барьерная метрика (агрегации по `paid_amt` и пользователям среди завершённых заказов);
  - вспомогательная метрика: конверсия из `order_initiate` в `order_create` (по событиям).
- **Статистическая проверка**: сравнение групп (в ноутбуке используется Welch t‑test через `scipy.stats.ttest_ind`; для метрики‑отношения применяется линейризация через агрегацию по пользователям).

Технически:
- библиотеки: `pandas`, `matplotlib`, `scipy.stats` (в т.ч. `ttest_ind`, квантили `t.ppf`);
- источники данных подгружаются по URL `https://code.s3.yandex.net/datasets/...`.

### `Python_AB_tests_3.ipynb`

В ноутбуке выполнен анализ исторических данных и результатов A/B‑эксперимента:
- **Исторические данные**: предобработка и EDA по датам/платформам/странам, построение динамики ключевой метрики.
- **Ключевая метрика**: рассчитывается как `total_amount / users_count` (средний депозит на пользователя) и визуализируется в динамике; для A/B‑данных строится динамика по группам.
- **Статистика по A/B**:
  - Z‑тест долей для конверсии `registration → first_deposit` (через `statsmodels.stats.proportion.proportions_ztest`);
  - Z‑тест долей для конверсии `first_deposit → second_deposit`;
  - разрез по `risk_level`: расчёт конверсии во второй депозит и сравнение групп через Z‑тест по уровням риска (в ноутбуке есть вспомогательные функции `prepare_ztest_data()` и `get_pvalue()`).
- **Сумма депозитов на платящего пользователя**: расчёт суммарных депозитов по пользователям и сравнение распределений между группами Welch t‑test (`scipy.stats.ttest_ind`, `equal_var=False`).
- **Пример bootstrap‑теста**: демонстрация бутстрап‑подхода на синтетических данных (разница 95‑х перцентилей и доверительный интервал).

Технически:
- библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `statsmodels.stats.proportion`;
- источники данных подгружаются по URL `https://code.s3.yandex.net/datasets/...`.

### `Data_analysis_diploma.ipynb`

В ноутбуке выполнен полный цикл продуктовой аналитики по маркетплейсу:
- **Данные**: `Orders`, `Users`, `Events`, `Campaign_costs`; выручка маркетплейса считается как `revenue = 0.05 * total_price`.
- **Обзор метрик (этап 2)**: динамика Revenue/ARPU/ARPPU/AOV и других базовых показателей за 2024 год.
- **Монетизация и юнит‑экономика (этап 3)**:
  - ретеншн по когортам регистрации;
  - конверсия по этапам воронки и её динамика;
  - CAC, LTV и ROI по месяцам, включая когортный ROI.
- **Поиск инсайтов и сегментация (этап 4)**: сравнение воронки и поведения по `gender`, `region`, `buyer_segment`, `os`, `device`, `acq_channel`; анализ рекламных затрат и качества привлечения по каналам.
- **Эксперимент (этап 5)**: дизайн и оценка A/B‑эксперимента «бонус на первую покупку для TikTok» (основная метрика — конверсия; также ARPU/ARPPU/AOV и барьерная метрика Revenue) с выводами по результатам.

Технически:
- библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `plotly`, `scipy`, `statsmodels.stats.proportion`;
- источники данных подгружаются по URL `https://code.s3.yandex.net/datasets/...`.
