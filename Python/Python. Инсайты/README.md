# Проект: Аналитика данных сервиса доставки "Всё.из.кафе"

## О проекте
Анализ выполнен на основе датасета событий пользователей сервиса доставки еды. Цель: найти инсайты для роста удержания пользователей и улучшения взаимодействия с ресторанами.

## Структура работы
1. Загрузка данных и предобработка
2. Анализ пользовательской воронки
3. RFM-сегментация клиентов
4. K-Means кластеризация ресторанов
5. Итоговый вывод и бизнес-рекомендации

## Что сделано
- Загружены данные и выполнена первичная проверка качества (dtype, пропуски, дубликаты, временные границы).
- Построена воронка пользовательского пути с шагами: `authorization`, `main_page`, `reg_page`, `confirm_phone`, `object_page`, `add_to_cart`, `order`.
- Рассчитаны конверсии:
  - общая (от первого шага)
  - step-by-step (от предыдущего шага)
- Проведено сравнение воронок для `Mobile` и `Desktop`.
- Выполнена RFM-сегментация (R, F, M):
  - Recency = дни с последней покупки
  - Frequency = число заказов
  - Monetary = сумма трат
- Построены гистограммы распределений R, F, M.
- Сформированы RFM-группы и определены ключевые сегменты.
- Для ресторанов рассчитаны признаки:
  - общее количество заказов
  - средний чек
  - число уникальных блюд
- Проведена K-Means кластеризация и визуализированы кластеры.

## Ключевые инсайты
- Потери пользователей критичны на этапе `confirm_phone`, особенно для `Mobile`.
- Основная клиентская база — средние пользователи (низкая частота и низкий чек).
- Выделен сегмент «китов» с высоким LTV, который важно удерживать.
- Рестораны разделяются на 4 кластера: доступные «массовые», слабые, премиум и средние.

## Рекомендации
1. Исправить UX/технические проблемы подтверждения номера: ускорение SMS, упрощение формы.
2. Для среднего сегмента клиентов ввести акции:
   - порог бесплатной доставки
   - скидки на средний чек
   - триггерные уведомления.
3. Для VIP-клиентов внедрить персональные предложения и поддержку.
4. Ресторанам из слабых кластеров предложить помощь: обучение, промо, улучшение каталога.
