# Python · Исследовательский анализ и визуализация

Проект по EDA и визуализации на данных заведений общественного питания Москвы.

## Структура папки

- `Задача.txt` — постановка задачи и перечень шагов.
- `Проект 7 спринта.ipynb` — ноутбук с предобработкой, исследовательским анализом, визуализациями и рекомендациями.

> Примечание: в этой папке нет файлов `*.py`. Вся работа выполнена в `.ipynb`.

## Постановка задачи (кратко)

Даны два датасета:
- `/datasets/rest_info.csv` — информация о заведениях (район, категория, рейтинг, сетевость, места, режим работы и др.).
- `/datasets/rest_price.csv` — информация о ценовой категории и среднем чеке.

Нужно:
1. загрузить данные, изучить состав и качество, объединить датасеты;
2. выполнить предобработку (типы, пропуски, дубликаты, новые признаки);
3. провести EDA и визуализировать ответы на исследовательские вопросы (категории/районы/сетевость/места/рейтинг/корреляции/топ сетей/средний чек по районам);
4. сформулировать итоговые выводы и рекомендации.

## Что сделано в `Проект 7 спринта.ipynb`

- **Загрузка данных**: чтение `rest_info.csv` и `rest_price.csv` по URL, первичная проверка структуры, типов, дублей.
- **Объединение**: `merge` по `id` в единый датафрейм для дальнейшего анализа.
- **Предобработка**:
  - оптимизация типов данных;
  - анализ пропусков (в ноутбуке есть вспомогательная функция `show_missing_stats()`), обработка части пропусков (например, `seats` заполняются значением `-1` как маркер «нет данных»);
  - поиск явных/неявных дублей (нормализация текстовых полей);
  - создание признака `is_24_7` по полю `hours` (`ежедневно, круглосуточно`).
- **EDA и визуализации**:
  - распределение заведений по категориям;
  - распределение по административным округам и отдельный разрез по ЦАО;
  - доля сетевых/несетевых заведений в целом и по категориям;
  - анализ `seats` (выбросы/аномалии) и «типичное» число мест по категориям;
  - сравнение рейтингов по категориям;
  - корреляционный анализ рейтинга с признаками (используется `phik`/`phi_k` для матрицы корреляций);
  - топ‑15 популярных сетей и их средние рейтинги;
  - анализ `middle_avg_bill` по районам и влияние удалённости от центра.
- **Итог**: выводы и рекомендации по результатам анализа.

## Как запустить

1. Откройте `Проект 7 спринта.ipynb` в Jupyter/VS Code.
2. Установите зависимости: `pandas`, `numpy`, `matplotlib`, `seaborn`, `phik`.
   - В ноутбуке есть ячейка `!pip install phik -U` (можно выполнить её или установить пакет заранее).
3. Запустите ячейки по порядку.

Если нет доступа к интернету, скачайте датасеты локально и замените URL в `pd.read_csv(...)` на пути к файлам.
