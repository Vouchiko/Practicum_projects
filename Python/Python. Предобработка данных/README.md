# Python · Предобработка данных

Папка с двумя учебными задачами по подготовке датасетов к анализу. Каждая задача оформлена отдельным файлом постановки (`.txt`) и отдельным ноутбуком (`.ipynb`).

## Структура папки

- `Задача_1.txt` — постановка задачи 1 (игры) + краткое summary.
- `Python_preprocessing_1.ipynb` — предобработка датасета по играм (`new_games.csv`).
- `Задача_2.txt` — постановка задачи 2 (стартапы) + список исследовательских вопросов.
- `Python_preprocessing_2.ipynb` — предобработка и подготовка витрин для анализа стартапов (несколько таблиц).

> Примечание: в этой папке нет файлов `*.py`. Вся работа выполнена в `.ipynb`.

## Задача 1 — игры (`Задача_1.txt` / `Python_preprocessing_1.ipynb`)

Цель: познакомиться с данными, проверить корректность и провести предобработку, получив релевантный срез данных.

Датасет: `/datasets/new_games.csv` (продажи по регионам, платформа/жанр, год релиза, рейтинги/оценки).

Что сделано:
- **Схема данных**: приведение названий к `snake_case`, типов — к корректным (`year_of_release` → `Int64`, `user_score/eu_sales/jp_sales` → числовые, `genre/platform` → `category`).
- **Пропуски**: удаление строк с пустыми `name/genre/eu_sales/jp_sales`, заполнение `critic_score/user_score` индикатором `-1`, `rating` — пустой строкой `''`.
- **Дубликаты**: нормализация `genre/platform` и `drop_duplicates()`.
- **Срез данных**: фильтрация по периоду **2000–2013**.
- **Категоризация**: признаки `user_rating` и `critic_rating` (высокая/средняя/низкая), топ‑7 платформ по числу игр.

Используемые библиотеки: `pandas`.

## Задача 2 — стартапы (`Задача_2.txt` / `Python_preprocessing_2.ipynb`)

Цель: подготовить датасет к работе и проанализировать структуру финансирования стартапов, чтобы сделать выводы и рекомендации «как инвестировать, если бы на дворе был 2015 год».

Данные загружаются из нескольких таблиц (по URL):
- `acquisition.csv` — сделки по покупкам компаний;
- `company_and_rounds.csv` — компании и раунды финансирования;
- `people.csv`, `education.csv`, `degrees.csv` — сотрудники и данные об образовании.

Что сделано:
- **Загрузка и первичная предобработка**: чтение таблиц, проверка `info()`, нормализация/переименование колонок (в т.ч. в `company_and_rounds.csv`).
- **Предварительное исследование**:
  - динамика раундов/объёмов финансирования по годам;
  - оценка полноты данных об образовании и возможности связывать `people/education/degrees`.
- **Объединение и подготовка витрин**: сбор объединённых таблиц для дальнейшего анализа.
- **Анализ выбросов и аномалий**: поиск типичных/нетипичных значений объёмов финансирования (в т.ч. кейсы «куплены за $0/$1 при ненулевом funding_total»).
- **Сравнения по категориям**: анализ цен/покупок стартапов по категориям, анализ числа раундов (`funding_rounds`) до покупки.

Используемые библиотеки: `pandas`, `matplotlib`, `seaborn`, `phik` (phi_k‑корреляции), `matplotlib_venn`.

## Как запустить

1. Откройте нужный ноутбук (`Python_preprocessing_1.ipynb` или `Python_preprocessing_2.ipynb`) в Jupyter/VS Code.
2. Установите зависимости:
   - для задачи 1: `pandas`;
   - для задачи 2: `pandas`, `matplotlib`, `seaborn`, `phik`, `matplotlib-venn`.
3. Запустите ячейки по порядку.

Если нет доступа к интернету, скачайте датасеты локально и замените URL в `pd.read_csv(...)` на пути к файлам.
