# Python · Статистика

Папка с учебным проектом по статистике и проверке гипотез на данных сервиса проката самокатов **GoFast**. Основной артефакт с Python‑кодом — Jupyter‑ноутбук (`.ipynb`) и текст постановки задачи.

## Структура папки

- `Python_statistics.ipynb` — проект: предобработка данных, EDA, расчёт выручки, проверка гипотез и работа с распределениями.
- `task.txt` — постановка задачи и описание данных.


## Постановка задачи (из `task.txt`)

Роль: аналитик сервиса проката самокатов GoFast. Даны три датасета:
- `users_go.csv` — пользователи (возраст, город, тип подписки `free/ultra`);
- `rides_go.csv` — поездки (дистанция, длительность, дата);
- `subscriptions_go.csv` — параметры подписок (цены, ежемесячный платёж).

Нужно:
- загрузить данные и выполнить предобработку (типы, пропуски/дубли, признаки по дате);
- провести EDA (города, доли подписок, распределения возраста/дистанции/длительности);
- объединить таблицы и сравнить поведение `free` vs `ultra`;
- посчитать помесячную выручку на пользователя;
- проверить гипотезы (длительность поездок, расстояние относительно 3130 м, выручка);
- поработать с распределениями (CDF/PPF), оценить доли поездок > 30 минут, 20–30 минут и найти 90‑й процентиль дистанции.

## Что сделано в `Python_statistics.ipynb`

Ноутбук структурирован по шагам из задания:
- **Загрузка данных**: чтение CSV по URL через `pandas.read_csv`, первичный просмотр и размеры таблиц.
- **Предобработка**: преобразование `date` в `datetime`, добавление `month`, поиск/обработка пропусков и дублей, округление и приведение `duration` к целому типу.
- **EDA**: визуализации (в т.ч. гистограммы и круговая диаграмма) по городам, подпискам, возрасту, дистанциям и длительности поездок.
- **Объединение**: `merge` пользователей/поездок/подписок (left join по `subscription_type`), разбиение на `df_free` и `df_ultra` и сравнение распределений.
- **Выручка**:
  - группировка по `user_id`, `name`, `subscription_type`, `month` и расчёт агрегатов (число поездок, суммарная длительность, суммарная дистанция);
  - функция `calculate_monthly_revenue(row)` для расчёта `monthly_revenue` по формуле из задания.
- **Проверка гипотез**:
  - подготовка выборок для `free` и `ultra`;
  - функция `print_stattest_results(p_value, alpha)` для интерпретации p‑value относительно уровня значимости;
  - применение статистических тестов из `scipy.stats` (по результатам — выводы о принятии/непринятии H1).
- **Распределения**: расчёт выборочного среднего/СКО длительности поездок и использование функций распределения (CDF/PPF) для оценки вероятностей и пороговых значений (в т.ч. 90‑й процентиль).

Используемые библиотеки: `pandas`, `matplotlib.pyplot`, `scipy.stats`.
