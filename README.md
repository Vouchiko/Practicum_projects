<a id="usage"></a>
## Как просматривать материалы
- SQL: файлы `*.sql` рассчитаны на запуск в SQL‑клиенте (в проектах встречается PostgreSQL‑синтаксис: `::type`, `FILTER`, `PERCENTILE_DISC`).
- Python: откройте `*.ipynb` в Jupyter/VS Code; зависимости — стандартный стек анализа данных (pandas/numpy/matplotlib/seaborn и т.п.).
- DataLens: ссылки на дашборды лежат в файлах `Ссылка на дашборд` (доступ зависит от прав/аккаунта).
