# SQL · Проект

Папка с итоговым SQL‑проектом: набор ad hoc запросов к учебной БД недвижимости и сопутствующие материалы (ответы и дашборд).

## Структура папки

- `Ad hoc запросы.sql` — три аналитических SQL‑запроса по рынку недвижимости (PostgreSQL).
- `Ответы на вопросы.docx` — текстовые ответы/выводы по результатам запросов.
- `Ссылка на дашборд` — ссылка на дашборд в DataLens (лежит в отдельном файле).

## Что сделано в `Ad hoc запросы.sql`

Во всех задачах используется общая логика подготовки данных:
- фильтрация выбросов по признакам квартиры через перцентили (`PERCENTILE_DISC` для `total_area`, `rooms`, `balcony`, `ceiling_height`);
- расчёт стоимости квадратного метра: `last_price / total_area`;
- соединение таблиц `real_estate.flats` и `real_estate.advertisement` (и при необходимости справочников);
- группировки и расчёт агрегатов (count/avg/median через `percentile_disc(0.5)`).

### Задача 1 — «Время активности объявлений»

Сегментация объявлений по длительности экспозиции (`days_exposition`) и сравнение характеристик по регионам:
- сегменты: месяц (1–30), квартал (31–90), полгода (91–180), больше полугода (>180);
- разрез по региону: Санкт‑Петербург (`city_id = '6X8I'`) vs Ленобласть;
- расчёт: количество объявлений, средняя цена за кв. метр, средняя площадь, медианы по комнатам/балконам/этажу.

### Задача 2 — «Сезонность объявлений»

Анализ сезонности публикаций и снятий объявлений:
- рассчитываются месяц публикации и месяц снятия (по `first_day_exposition` и `first_day_exposition + days_exposition`);
- ограничение по годам публикации: 2015–2018;
- агрегирование по месяцу публикации: число регистраций/снятий, средняя цена за кв. метр и средняя площадь.

### Задача 3 — «Рынок недвижимости Ленобласти»

Сравнение активности объявлений по городам Ленобласти:
- исключается Санкт‑Петербург (`city_id <> '6X8I'`);
- для каждого населённого пункта считаются:
  - общее число объявлений и число «снятых» (на основе `last_day_exposition <= CURRENT_DATE`);
  - доля снятых объявлений (%);
  - средняя цена за кв. метр, средняя площадь, средняя продолжительность публикации;
- выводится топ‑15 городов с `HAVING COUNT(*) > 50`.

## Как использовать

1. Откройте `Ad hoc запросы.sql` в SQL‑клиенте.
2. Выполняйте запросы по отдельности (они разделены комментариями `-- 1`, `-- 2`, `-- 3`).
3. Предполагается PostgreSQL‑диалект и наличие схемы/таблиц `real_estate.*` из учебной среды.
